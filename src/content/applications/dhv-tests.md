The DHV test centre examines new paragliders, hang gliders, reserves, and harnesses and publishes the reports. The equipment database is the place to look up a wing before you buy it or fly it: the weight range, the class, and the flight-test notes.

A class is the most demanding result from a set of standard maneuvers. It is not a review of how the wing feels on a thermal day, and it is not a measure of performance. Read the report for the size you will fly. A wing can sit in a different class at a different size.

The test is flown in a set way, in settled air. Your collapse, in turbulence, on your harness, will not match the video. The report still tells you how that model behaved when someone provoked it on purpose.
