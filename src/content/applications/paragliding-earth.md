Paragliding Earth is a public directory of flying sites. A page for a launch holds the location, the wind directions it faces, and whatever description a pilot has added. SpotAiR and other maps reuse those points, so a correction here shows up elsewhere.

Treat every page as a note from another pilot, not as a site guide from the local club. Wind directions go out of date, landing fields get built on, and access rules change. Read the local club or the national association before you fly somewhere new.

If you fly a site that is missing or wrong, the useful edit is the one you make after you have landed and checked the facts.
