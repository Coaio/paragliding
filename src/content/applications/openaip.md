OpenAIP is a public airspace database. Flight apps, including XCTrack and XCSoar, download it so the map can draw controlled airspace, restricted areas, and the frequencies that go with them. The website is where you look a place up before you copy the file onto a phone.

Airspace changes. Load a fresh file for the trip, and treat a NOTAM or the national AIP as newer than the file in your pocket. An app warning is only as current as the last download.

You can also browse the map in a browser when you are planning a route and you do not want to open the instrument yet.

[OpenAIP](https://www.openaip.net/)
